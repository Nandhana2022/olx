# 🛒 OLX Clone (React + Vite)

An OLX-inspired classified ads application built with **React (Vite)**.  
It provides a clean, responsive UI for browsing and managing ads.

---

## 🚀 Live Preview
👉 [OLX Clone App](https://olx-ivory.vercel.app/)

---

## 📦 Features
- Browse ads in a modern UI
- Responsive design for desktop and mobile
- Component-based architecture
- Easy to extend with backend API

---

## 🛠 Tech Stack
- React + Vite
- TailwindCSS (for styling)
- React Router (for navigation)
- Axios (for API integration, if added)
